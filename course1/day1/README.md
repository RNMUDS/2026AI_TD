レポートは **自グループの実測 ＋ 質問カード交換（第2回）で集めた 3〜4 グループの実測値** を比較して作成する．提出されたグループの分は教員が統合図として全体共有で投影する．

## 演習の進め方

1. ノートブックの **(0) グループと役割の設定** で `GROUP_ID` と `MEMBER_ROLE` を書き換える
2. ブロックを上から順に実行し，`TODO` を埋める．**implementer だけがコードを書く**
3. verifier は implementer の隣で条件を変えて再実行する（例：バッチサイズ，繰り返し回数）
4. recorder は出たエラーと直し方，討議で割れた点を `results/` に残し，そこから他グループへの質問を 3 問作る（`waiting_task.md` 参照）
5. presenter は討議の進行と時間管理を行い，グループの結論を一文にまとめ，プレゼンと全体共有でグループを代表して話す．質問カード交換では他グループ 3〜4 グループ分の実測値を集める

**グループが 3 人のとき**：presenter を verifier が兼任する（`MEMBER_ROLE` は "verifier"）．3 役を日替わりで回す．
**グループが 5 人のとき**：5 つ目の役割 **collector**（収集係）を置く．質問カード交換で他グループ 3〜4 グループ分の実測値（演習2 の表と演習3 の順位）を集め，時間管理も担う．implementer は増やさない（コードを書くのは 1 人のまま）．

### GW3（ex0）コードを組み立てる

授業ページのカード A〜L（教科書のコード 12 枚，順不同）を，`ex0.ipynb` の①〜⑫の空セルに貼って実行する（試行① MLP × FashionMNIST）．
続いて差し替えカードで試行②（M〜Q：MLP × オリジナル画像 `assets/cable1/`）と試行③（R：シンプルな CNN）を実行する．いずれも 20 エポック．
生成は `instructor/build_ex0.py`（教科書 `no02`・`no04-2`・`no07-1` から作る）．

### 演習1（E1-1）環境ベンチマーク

自分のマシンの帯域（GB/s）・演算（GFLOPS）・学習ステップ時間（ms/step）を測り，CSV に投稿する．
要点は **(4) 同期しないと何が起きるか**．MPS では同期の有無で 10 倍以上異なる．

### 演習2（E1-2）学習済みモデルの同時測定

A1（埋め込み平均＋MLP）・A2（1次元畳み込み）・A3（小型 Transformer）はパラメータ数を約 30 万に揃え，
同じデータ・同じ条件で学習済み．正解率・損失・推論時間・メモリを **同じ関数で** 測って 1 枚の表にする．
**実行前に `waiting_task.md` の予測欄を埋める．**

### 演習3（E1-3）「良いAI」の定義と順位

グループで「良いAI」を一文で定義し，正規化の方法（minmax か rank）を選び，4 指標に重み（合計 1）を付けて順位を出す．
**他グループと順位が食い違うこと** を次のプレゼンで確認する．同じ数値から違う結論が出る理由を話す．

## グループ別条件

なし．演習3 の重み付けのみグループが自由に決める（`conditions.yaml`）．

## 提出物（**一人ひとりが個人で提出**，`results/` 以下）

グループでデータを共有し，各自が自分の提出ファイルを作って，自分で提出する．

| ファイル | 内容 |
|---|---|
| `ex0.ipynb` | GW3 でコードを貼って実行したノートブック（`course1/day1/`） |
| `c1_d1_ex0_<グループ>.csv` | GW3 の試行①②③の正解率・学習時間 |
| `c1_d1_ex1_<グループ>.csv` | ベンチマーク結果（グループ全員分の行） |
| `c1_d1_ex2_<グループ>.csv` と `table_c1_d1_ex2_<グループ>.csv` | 3 モデル × 4 指標（＋任意 3 指標） |
| 穴埋めシート（PDF） | 記入済みのもの（グループで共有し，各自が提出物に含める） |

提出前に `python course1/day1/verify.py --group <グループ番号>` で形式を確認する．

1. **グループで共有する**：演習1 の CSV（各自の行），穴埋めシート，recorder の失敗記録・討議メモを AirDrop・Slack などでグループ全員に配る
2. **自分で提出ファイルを作る**：共有された演習1 の行を自分の `results/` に集める．GW3 の `ex0.ipynb` と演習2 は自分のマシンで実行した結果を使う
3. **自分で提出する**：zip にせず，上記のファイルをそのまま個別に [Open-LMS](https://musashino-u.myopenlms.net/course/view.php?id=7914) の課題「第1回」へアップロードする．代表者がまとめて出すのではなく，**全員がそれぞれ提出**する

ファイル名のグループ番号は変えない．教員側は「すべての提出をダウンロード」した zip を `instructor/import_lms.py` で `results/` に取り込み，`verify.py` と `aggregate/` をそのまま回す．

## グループ内プレゼン（各 10 分，スライド禁止，画面を見せて話す）

presenter がグループの結論を 2 分で話し，他の 3 名が 1 分ずつ補足する．残り 5 分は質疑．

| 役割 | 話すこと |
|---|---|
| implementer | どの TODO で行き詰まったか．同期を入れる前後で数値がどう変わったか |
| verifier | 条件を変えて何が変わったか（繰り返し回数，バッチサイズ，指標の向き） |
| recorder | 出たエラーと直し方，討議で割れた点，そこから作った他グループへの質問 3 問 |
| presenter | グループの結論（一文）と，その根拠となる数値 |
