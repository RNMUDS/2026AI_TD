1回の結果では「差がある」とは言えない

教員機・ケーブル画像（テスト 30 枚）。点は 5 回の各回、白い線は平均 ± 標準偏差。点に重ねると値が出る。

シードを変えると変わるもの

データの分け方・重みの初期値・ミニバッチの順。写真とモデルの形は変わらない。

差 ÷ 標準偏差判定
2 以上差がある
1 以上 2 未満どちらとも言えない
1 未満差があるとは言えない

差 6.7 ポイント ÷ 標準偏差 9.7 ＝ 0.7 → 差があるとは言えない。シード 1 だけ両方とも大きく下がった（分け方の当たり外れ）。

⑧⑨凍結 model.fc.parameters()・0.001／微調整 model.parameters()・0.0001

NUM_CLASSES = len(full_dataset.classes)
from torchvision.models import ResNet18_Weights
model = models.resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)
for param in model.parameters():      # 凍結のときだけ
    param.requires_grad = False
num_ftrs = model.fc.in_features             # 512
model.fc = nn.Linear(num_ftrs, NUM_CLASSES)  # 最終層を替える
for param in model.fc.parameters():   # 凍結のときだけ
    param.requires_grad = True
model = model.to(device)
