第4回補足 ― MLP・CNN の部品

Flatten・全結合・畳み込み・プーリング

Flatten（MLP）

画像 3×64×64 を 12,288 個の1列に並べ替える。値は変えず、重みも無い。上下の隣どうし（図の 1 と 4）が離れ、位置の関係が消える。

全結合（MLP・CNN）

出力1個 ＝ 入力の全部 × 重み の合計 ＋ バイアス。12,288 → 512 だけで 12,288×512＋512 ≒ 629万個（MLP の約98%）。

畳み込み（CNN）

3×3 の窓（フィルタ）を1画素ずつずらし、窓の中 × 重み の合計を出す。同じ窓を画像全体で使い回すので、重みは (3×3×3＋1)×16枚 ＝ 448個。何を拾う窓になるかは学習で決まる。

プーリング（CNN）

2×2 ごとに最大値を1つ残し、縦横を半分にする（64×64 → 32×32）。重みは無い。位置が少しずれても同じ値になりやすい。

CNN の重み 約210万個のほぼ全部は、プーリング後の全結合（16×32×32 ＝ 16,384 → 128）にある

第4回補足 ― シードと5回

なぜシードを変えて5回ずつ回したのか

シード（乱数の種）とは

乱数を作る出発点の数。同じシードなら同じ乱数が出るので、同じ結果を出し直せる（再現性）。

シードを変えると、どの写真がテストになるか・重みの初期値・ミニバッチの順が変わる。同じシードなら、比べるモデルどうしで同じ写真を使う（公平な比較）。

なぜ1回ではだめか

1回の差は、モデルの違いか、分け方の当たり外れかを区別できない。第4回ではシード1だけ両方とも大きく下がった。

なぜ5回か

何回か回すとばらつき（標準偏差）が測れる（2回以上必要）。回数を増やすほど平均は安定するが時間もかかる。5回は授業時間内に回せる回数。

差 ÷ 標準偏差 ＝ 差がばらつきの何個分か

標準偏差は2つを2乗平均：√((11.3² ＋ 7.8²) ÷ 2) ≒ 9.7。差 6.7 ÷ 9.7 ＝ 0.7。ばらつきより小さい差は、偶然でも出る。

第4回補足 ― 判定の基準

「差がある」を何で決めるか：差とばらつきの比

教員機・ケーブル画像の実測。点は5回の各回、白い線は平均。

見るのは2つ

平均の差とばらつき（標準偏差）。差 ÷ 標準偏差 ＝ 差がばらつきの何個分か。

なぜ「2」と「1」か

本当は差が無くても、シードの当たり外れだけで比がその値以上になる割合（5回ずつのとき）：

比偶然で出る割合だから
1約15%（よく出る）1未満は言えない
2約1%（まれ）2以上は差がある
割合は t 検定による目安（5回ずつ・ばらつきが正規分布に近いとき）

第5回補足 ― 何層まで学習し直すか

何層まで学習し直すか：後ろの層から、検証で決める

ImageNet に似ている似ていない
写真が少ない凍結（fc だけ）凍結。足りなければ後ろの数層
写真が多い後ろの数層〜全層全層

少ないのに多くの層を動かすと合わせすぎ（過学習）になりやすい。似ていないほど入口まで直す意味がある。境目の枚数に決まった値は無い（CS231n の整理）。

決め方の手順

  1. 凍結で回し、基準の正解率を出す
  2. fc → layer4 → layer3 … と後ろから1ブロックずつ広げ、検証の正解率を見る
  3. 上がらなくなったら止める。テストは最後に1回だけ
  4. シードを変えて複数回回し、差 ÷ 標準偏差で判定する
学習する層の数も、学習率と同じく自分で決める設定の1つ。層ごとに学習率を変える（前の層ほど小さく）やり方もある

第5回補足 ― 一部の層だけ凍結するコード

layer4 と fc だけを学習する ⑦⑧⑨ の書き方

NUM_CLASSES = len(full_dataset.classes)
model = models.resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)

for param in model.parameters():          # 1 いったん全部を凍結
    param.requires_grad = False

num_ftrs = model.fc.in_features
model.fc = nn.Linear(num_ftrs, NUM_CLASSES)    # 2 新しい fc は学習する

for param in model.layer4.parameters():   # 3 layer4 の凍結を解く
    param.requires_grad = True
model = model.to(device)

# ⑧⑨ 学習する重みだけを渡す（学習率は微調整と同じ）
criterion = nn.CrossEntropyLoss()
optimizer = optim.Adam(
    [p for p in model.parameters() if p.requires_grad],
    lr=0.0001)

requires_grad = False の意味

その重みの勾配を計算しない → optimizer.step() で値が変わらない（凍結）。

凍結を解く範囲を変える

3 に model.layer3 も足せば後ろ2ブロック。名前は次で確かめる：

[n for n, _ in model.named_children()]
# conv1 bn1 relu maxpool layer1 layer2
# layer3 layer4 avgpool fc

学習する数：8,394,754（全体の約75%）

凍結しても BatchNorm の平均・分散は model.train() のあいだ更新される（重みとは別）
