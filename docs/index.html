人工知能(AI)テクノロジデザインⅠ（AI_TD1）─ 2026年度 3学期

武蔵野大学データサイエンス学部　中村 亮太

その数字は信じられるか ― 深層学習の実験方法論

ディープラーニングモデルを構築し、学習させ、自分のマシンで測り、他グループの実測値と比べて「差があると言えるか」を判定する。

📌 科目の概要

  • 150分 × 7回（3学期・木曜3〜4限・有明 5-501/502）。2年次必修
  • 各自の MacBook Air（Apple Silicon）で PyTorch を動かす
  • 4名1グループ。役割は毎回交代
  • 教科書『データサイエンティストのためのディープラーニングプログラミング』（サイエンス社）のコードを参照する
1

到達目標

目標できること
⓪ 組み立てるニューラルネットワークの学習の流れ（データ準備 → 学習設定 → 学習・評価）とディープラーニングプログラミングの型を使ってモデルを作り、用語（損失関数・誤差逆伝播・最適化手法・過学習など）を正しく使える
① 正しく測る同期・ウォームアップ・中央値で4指標を測れる
② 差を疑うシード5回の平均と標準偏差で差を判定できる
③ 公平に比べるパラメータ数を揃えて構造を比べ、解けない壁を示せる
④ 言葉にする実測値を根拠に説明できる
2

授業計画（全7回）

回テーマやること
1学習の流れ・組み立て・測定コードを組み立てる（MLP・CNN）／環境ベンチマーク
2勾配の観測3モデルの4指標／「良いAI」の定義と順位／層別勾配ノルム
3過学習と評価指標過学習を作る／正則化3手法
4 ★再現性と分散シード5回／差 ÷ 標準偏差（以後の既定）
5アーキテクチャ比較27セルの格子を分担して埋める
6ショートカット学習相関トークン／反転テスト
7スケーリング則16セル／外挿して当てる

※ 4学期のⅡ（第8〜14回）は「他人が使えるか」を問う。

3

進め方とルール

  • 演習ごとに 予測 → 実行 → 討議 → グループ内プレゼン（スライドなし）
  • 成績は課題提出 100%。データはグループで共有し、各自が Open-LMS に提出する
  • LLM の利用は自由。ただし自分で読み、測って確かめる
4

各回の資料

1公開AIは何を学習し、モデルをどう組み立て、どう測るか 2準備中勾配の観測 3準備中過学習と評価指標 4準備中再現性と分散 5準備中アーキテクチャ比較 6準備中ショートカット学習 7準備中スケーリング則
