人工知能(AI)テクノロジデザインⅠ（AI_TD1）─ 2026年度 3学期

武蔵野大学データサイエンス学部　中村 亮太

その数字は信じられるか ― 小型言語モデルで学ぶ深層学習の実験方法論

自分のマシンで小型の言語モデルを動かし、正解率・損失・速度・メモリを自分で測る。班ごとに違う条件を担当し、他班の実測値と比較して「差があると言えるか」を判定する方法を身につける。

📌 科目の概要

  • 150分 × 7回（3学期・木曜3〜4限・有明 5-501/502）。2年次必修
  • 受講者は自分の MacBook Air（Apple Silicon）で PyTorch（MPS）を動かす。クラウド GPU は使わない
  • 4名1班のグループワーク。役割（implementer／verifier／recorder／presenter）を毎回交代する
  • 毎回、班別条件（ジグソー）で実験する。レポートは自班の実測と、質問カード交換で集めた3〜4班の実測値を比較して作成する。提出された班の分を教員が統合した図を配る
  • 各演習の後にグループディスカッションとグループ内プレゼンを必ず行う。授業の後半は班間の質問カード交換

教科書との関係

『データサイエンティストのためのディープラーニングプログラミング』（中村亮太、サイエンス社）は、モデル構築のプログラミングパターン（学習ループ・データセット・転移学習・デプロイ）の参照用として使う。授業の題材は画像分類ではなく小型言語モデルで、演習は GitHub から取得する授業用フォルダ AI_TD で進める。

1

到達目標

① 正しく測る
GPU の同期・ウォームアップ・中央値を使い、正解率・損失・速度・メモリを同じ関数で測れる。損失曲線を読んで「どこで止めるか」を判断できる
② 差を疑う
同一条件をシード5回で実行し、平均と標準偏差を出し、「差 ÷ ばらつき」で差があると言えるかを判定できる
③ 公平に比べる
パラメータ数を揃えたアーキテクチャ比較を設計・実行し、データ量で解決できない壁（語順を捨てるモデルは語順課題を解けない）を実測で示せる
④ 言葉にする
ショートカット学習やスケーリング則を自分の実測から説明し、他班に「実測値を要求する質問」を作れる

シラバス上の到達目標との対応

「先端AIテクノロジの特徴・課題を把握できる」（①③④）／「Python で課題に適したAIモデルをデザイン・実装できる」（①③）／「構築したモデルの適用範囲と有効性を論理的に説明できる」（②④）／「チームで協力して進められる」（毎回のグループワーク）

3

進め方とルール

毎回の型

  • 実行 → グループディスカッション（5〜10分）→ グループ内プレゼン（presenter 2分＋他の各1分）を演習ごとに1セット。スライドは作らない。画面を見せて話す
  • 結果を見る前に予測を書く。外れた予測がプレゼンの材料になる
  • 各班の recorder が質問3問を作り、別班へ渡して10分で回答、3段階で採点する。「相手の実測値を要求する質問」が最高評価。このやり取りで presenter が3〜4班分の実測値を集める
  • すべての計測結果は共通形式の CSV に記録し、教員が提出された分を1枚の図に統合して投影する。統合 CSV は授業後に LMS へ置く

評価と提出

  • 成績は課題提出 100%（必須課題・任意課題・授業内課題・グループワークの主体性）
  • 毎回、班で1セットの成果物（CSV・定義・質問カード・失敗記録）を LMS に提出。授業当日中の提出を目指す
  • LLM（大規模言語モデル）の利用は制限しない。ただし自班の実測値は LLM からは得られない。「作れたか」ではなく「読み解いて説明できるか」を見る
