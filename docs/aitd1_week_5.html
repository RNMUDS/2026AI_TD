ResNet18 は ImageNet（1000種類・約128万枚）で学習済み。最後の層の手前までが「画像の特徴を取り出す部分」で、自分の写真にもそのまま使える。

第4回 演習1 から変える所

テンプレート変える所
①from torchvision import models を足す
②Resize((224, 224))。ToTensor() のあとに transforms.Normalize([0.485, 0.456, 0.406], [0.229, 0.224, 0.225])（ImageNet で学習したときと同じ入力にする）
⑦下のコード
⑧⑨凍結：optim.Adam(model.fc.parameters(), lr=0.001)／微調整：optim.Adam(model.parameters(), lr=0.0001)
⑩凍結 EPOCHS = 20／微調整 EPOCHS = 10
NUM_CLASSES = len(full_dataset.classes)                    # クラス数
from torchvision.models import ResNet18_Weights
model = models.resnet18(weights=ResNet18_Weights.IMAGENET1K_V1)   # 学習済みの重みを読む
for param in model.parameters():                           # ← 凍結のときだけ：全パラメータを固定
    param.requires_grad = False
num_ftrs = model.fc.in_features                            # 最終層に入る数（512）
model.fc = nn.Linear(num_ftrs, NUM_CLASSES)                # 最終層（1000 クラス用）をクラス数に置き換える
for param in model.fc.parameters():                        # ← 凍結のときだけ：最終層だけを学習対象に
    param.requires_grad = True
model = model.to(device)
dummy_input = torch.randn(1, 3, 224, 224).to(device)
output = model(dummy_input)
print("出力の形状: ", output.size())                        # torch.Size([1, クラス数])
